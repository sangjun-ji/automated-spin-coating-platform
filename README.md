# HELIOS
>High-Efficiency Automated Lab Integration of Perovkite Solar Cells

---

## 1. Introduction
HELIOS is an automated system designed to improve the reproducibility and uniformity of thin-film fabrication. It eliminates human error by integrating hardware automation with software control. While versatile for various electronic devices, it is currently optimized for fabricating **Perovskite Solar Cells (PSCs)**.
